HW1: COVID-19 Cases Prediction (Regression)

根据美国各州过去5天的疫情调查数据，预测第5天的检测阳性率。

一、实验记录

1. Baseline

改动：官方sample code原始配置，SGD优化器，学习率1e-5，使用全部特征

结果：Valid Loss 2.746

说明：起点成绩，收敛很慢，跑满16000多步才勉强稳定下来

2. 更换优化器

改动：优化器从SGD改成Adam，学习率调整到1e-3

结果：Valid Loss 1.47

说明：相比baseline大幅提升，收敛速度也明显加快，8000步左右就基本稳定了。中间也发现一个问题：如果只换优化器不调学习率，反而会比原来更慢，说明这两个参数要配合调整

3. 加入特征选择

改动：在实验2的基础上，用相关性分析的方法，从117个原始特征里挑出16个跟目标值相关性最高的特征

结果：Valid Loss 1.164

说明：目前效果最好的一版，去掉冗余特征之后模型学习效率进一步提升

4. 调整模型架构 + 特征标准化

改动：在实验3的基础上尝试加深加宽网络，训练过程中一度出现明显过拟合，valid loss飙升到十几。排查后发现原始代码一直没有对输入特征做标准化处理，加入标准化之后训练变得稳定很多，同时加大了正则化力度

结果：Valid Loss 1.481

说明：训练稳定性明显改善，但最终loss比实验3略高一点

二、结论

换优化器加调整学习率是这次提升最明显的一步，两个参数必须配合调整才有效果，单独换优化器反而可能变慢。

特征选择效果最好，说明相关性高的特征更值得保留，砍掉冗余信息对模型有帮助。

尝试加大模型容量的时候出现了过拟合，排查后发现是数据没有标准化导致的，这也提醒自己以后写代码要养成检查数据预处理是否完整的习惯。加了标准化之后虽然没有让最终loss更低，但训练过程明显更稳定了。
