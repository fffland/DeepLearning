# HW1: COVID-19 Cases Prediction (Regression)

根据美国各州过去 5 天的疫情调查数据，预测第 5 天的检测阳性率。

## 实验记录

| 序号 | 改动 | 结果 (Valid Loss) | 说明 |
|---|---|---|---|
| 1 | Baseline：官方 sample code 原始配置，SGD 优化器，学习率 1e-5，使用全部特征 | 2.746 | 起点成绩，收敛很慢，跑满 16000 多步才勉强稳定下来 |
| 2 | 优化器从 SGD 改成 Adam，学习率调整到 1e-3 | 1.47 | 相比 baseline 大幅提升，收敛速度也明显加快，8000 步左右就基本稳定了。若只换优化器不调学习率，反而会比原来更慢，说明这两个参数要配合调整 |
| 3 | 在实验 2 基础上加入特征选择，用相关性分析从 117 个原始特征里挑出 16 个跟目标值相关性最高的特征 | 1.164 | 目前效果最好的一版，去掉冗余特征之后模型学习效率进一步提升 |
| 4 | 在实验 3 基础上尝试加深加宽网络，训练中一度出现明显过拟合（valid loss 飙升到十几）。排查后发现原始代码没有对输入特征做标准化，加入标准化后训练稳定很多，同时加大了正则化力度 | 1.481 | 训练稳定性明显改善，但最终 loss 比实验 3 略高一点 |

## 结论

- 换优化器加调整学习率是这次提升最明显的一步，两个参数必须配合调整才有效果，单独换优化器反而可能变慢。
- 特征选择效果最好，说明相关性高的特征更值得保留，砍掉冗余信息对模型有帮助。
- 尝试加大模型容量时出现了过拟合，排查后发现是数据没有标准化导致的，提醒自己以后要养成检查数据预处理是否完整的习惯。加了标准化之后虽然没有让最终 loss 更低，但训练过程明显更稳定了。
